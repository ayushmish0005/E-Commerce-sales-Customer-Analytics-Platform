# E-Commerce-Sales-Customer-Analytics-Platform
E-commerce sales and customer analytics dashboard built using Microsoft Power BI.
E-Commerce Sales & Customer Analytics Platform

Project Overview

This project is an interactive business intelligence dashboard developed using Microsoft Power BI. It analyses e-commerce sales, profitability, customer behaviour, regional performance, product categories, returns, and marketing campaigns.

The goal is to transform raw data into meaningful business insights that support data-driven decision-making.

Tools Used

- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

Key KPIs

- Total Revenue
- Total Profit
- Profit Margin
- Total Orders
- Total Customers
- Returned Orders

Dataset

The dataset is simulated for educational and project demonstration purposes.
